Objektif hari ini
1. Dapat menjelaskan bagaimana prompt ai yang lebih sepsifik dapat mengasilkan yang lebih baik
2. Dapat mengidentifikasi repository, commit, branch, dan pull request.
3. Dapat membedakan apa itu git dan github
4. Dapat melakukan version controlling

Prompt engineering
Cara merancang instruksi agar ai memberikan jawaban yang tepat, relevan, dan layak digunakan
Prompt adalah instruksi atau masukan yang anda berikan kepada model untuk mendapatkan hasil tertentu
contoh:
1. Without text
2. With context

Repository Tempat menyimpan proyek beserta riwayat perubahannya.

Branch Cabang pengembangan proyek.
Pull Request Permintaan untuk menggabungkan perubahan kode.
SSH Key Metode autentikasi untuk menghubungkan komputer dengan GitHub secara aman.

Git Setup:
1. Install Git
2. Atur username dan email
3. Cek versi Git

Yang harus di perhatikan:
1. Git = Mengelola perubahan kode.
2. GitHub = Penyimpanan kode online.
3. Commit = Menyimpan perubahan.
4. Push = Mengirim kode.
5. Pull = Mengambil kode.
6. Clone = Menyalin repository.
7. Branch = Cabang proyek.
8. Repository = Tempat penyimpanan proyek.
9.Prompt = Instruksi untuk AI.
